## Où ranger chaque projet

Un projet console par projet du cours, dans ta solution `ProjetEtudes` :

| Section du cours | Nom de projet suggéré |
|---|---|
| 3. Bases et premier programme | `Bases` |
| 4. Le nombre magique | `NombreMagique` |
| 5. Jeu de maths | `JeuDeMaths` |
| 6. Générateur de mots de passe | `MotsDePasse` |
| 7. Collections | `Collections` |
| 8. Générateur de phrases | `GenerateurPhrases` |
| 9. Jeu du pendu | `Pendu` |
| 10. POO | `Poo` |
| 11 et 15. Pizzas v1 et v2 | `Pizzas` (une seule appli qui évolue) |

Pour chaque nouveau projet :

```bash
dotnet new console -n NombreMagique --use-program-main
dotnet sln add NombreMagique/NombreMagique.csproj
dotnet run --project NombreMagique
```
